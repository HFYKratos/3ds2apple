# v0.1.0-alpha — 首个实验版本

[English](v0.1.0-alpha.md) | **简体中文**

这是 3ds2apple 的第一个公开实验版本：面向 iPhone / iPad 的原生 ARM64 3DS
运行时。本次以源码发布；GitHub Release 附带的 shell IPA **不含任何游戏代码**。

## 已实现

- iPhone / iPad 壳（iOS 16+），已在 iPhone 14 Pro Max（iOS 26.7.2）上构建和
  测试。
- 自带已解密的 `.3ds` / `.cci`；App 通过 Files 导入。
- AOT 重编译流水线：3dsrecomp → C → arm64，链接进 App。
- Zakuro HLE 运行时：CPU 兜底、系统服务、音频、输入、存档。
- 上下双屏按透视呈现：上屏 400×240，下屏 320×240。
- 触摸操作与 GameController 支持。
- 通过 AVAudioEngine 输出音频。
- 通过 CAMetalLayer 经 MoltenVK / Metal 呈现，并启用系统 Metal
  Performance HUD。
- 应用内诊断：帧时间 HUD 与 **Export diagnostics** 按钮，可写出包含
  设备/构建、AOT/显示状态、帧时间，以及当前和上一次会话日志的文本报告。
- Pipeline cache 持久化在 App 的 Caches 目录，第二次运行不会重复编译同一批
  pipeline。

用于测试 Pokémon Y 的开发构建，在 pipeline cache 预热后可在 A16 设备上达到
约 60fps。

## 不包含的内容

- **不含 ROM、解密密钥、系统文件或游戏资源。**
- **不含游戏专属 AOT IPA。** per-game 构建包含由用户游戏衍生的代码，只保留
  在用户自己的机器上，不对外分发。
- 附带的 shell IPA 仅使用解释器：它可以加载 ROM，但没有 per-game AOT 归档时
  会明显更慢。它的用途是让你试用 App/UI 并验证安装流程。

## 安装 shell IPA

shell IPA 未签名。请用 Sideloadly 或 AltStore 和你自己的 Apple ID 签名并
安装：

```text
3ds2apple-shell-v0.1.0-alpha.ipa
SHA256 8806cb521066c99b54f9b1901c13cf77220e59ac2f5937d6c91d5847e4bd276d
```

App 不包含游戏；请从 Files 导入你自己的已解密 ROM。想要可玩的 AOT 构建，请按
`docs/build.md` 在你自己的 Mac 上用你自己的 ROM 构建。

## 构建可玩的 per-game IPA

需要：装有 Xcode 的 macOS、带 `aarch64-apple-ios` 的 Rust，以及一份你自己
拥有的本地已解密 ROM。

```bash
scripts/build-recomp-ios.sh "path/to/game.cci" <name> --auto-serial
scripts/build-linked-ios-lib.sh <name>
MOLTENVK_FRAMEWORK=/path/to/MoltenVK.framework \
  scripts/build-game-ipa.sh <name> --display-name "Game name"
```

生成的 IPA 未签名；请用 Sideloadly / AltStore 签名。

## 已知限制

- 早期开发阶段；只验证了少量游戏。
- 首次运行时，新图形 pipeline 的编译可能造成卡顿；pipeline cache 会让后续
  运行流畅很多。
- UI 是单游戏壳：还没有游戏库、设置页、即时存档管理或屏幕菜单。
- 电池存档保存在 App 的 Documents 目录；导入/导出和即时存档 UI 尚未实现。
- 无相机、麦克风、联机、金手指或高清材质。
- 不通过 App Store 分发。
