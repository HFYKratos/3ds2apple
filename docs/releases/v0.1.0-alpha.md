# v0.1.0-alpha — first experimental build

This is the first public, experimental snapshot of 3ds2apple: a native ARM64
3DS runtime for iPhone and iPad. It is a source release; the shell IPA attached
to the GitHub release contains **no game code**.

## What works

- iPhone / iPad shell (iOS 16+), built and tested on an iPhone 14 Pro Max
  (iOS 26.7.2).
- Bring your own decrypted `.3ds` / `.cci`; the app imports it through Files.
- AOT recompilation pipeline: 3dsrecomp → C → arm64, linked into the app.
- Zakuro HLE runtime: CPU fallback, system services, audio, input, saves.
- Painter's-eye view of the two 3DS screens: upper 400×240 above lower
  320×240.
- Touch controls and GameController support.
- Audio output through AVAudioEngine.
- MoltenVK / Metal presentation through a CAMetalLayer, with the system Metal
  Performance HUD enabled.
- In-app diagnostics: frame-time HUD and an **Export diagnostics** button that
  writes a text report with device/build, AOT/display state, frame timings and
  the current + previous session logs.
- Pipeline cache is persisted in the app's Caches directory, so a second run
  does not recompile the same pipelines.

The development build used for testing Pokémon Y reaches ~60 fps on an A16
device once the pipeline cache is warm.

## What is NOT included

- **No ROMs, decryption keys, system files or game assets.**
- **No game-specific AOT IPA.** The per-game build contains code derived from
  the user's game; it stays on the user's machine and is not distributed.
- The attached shell IPA is interpreter-only: it can load a ROM, but without a
  per-game AOT archive it will be much slower. It is there to let you try the
  app/UI and verify the install path.

## Install the shell IPA

The shell IPA is unsigned. Sign and install it with Sideloadly or AltStore and
your own Apple ID:

```text
3ds2apple-shell-v0.1.0-alpha.ipa
SHA256 8806cb521066c99b54f9b1901c13cf77220e59ac2f5937d6c91d5847e4bd276d
```

The app does not include a game; import your own decrypted ROM from Files. For
a playable AOT build, follow `docs/build.md` and build the game on your own Mac
with your own ROM.

## Build a playable per-game IPA

Requirements: macOS with Xcode, Rust with `aarch64-apple-ios`, and a local
decrypted ROM you own.

```bash
scripts/build-recomp-ios.sh "path/to/game.cci" <name> --auto-serial
scripts/build-linked-ios-lib.sh <name>
MOLTENVK_FRAMEWORK=/path/to/MoltenVK.framework \
  scripts/build-game-ipa.sh <name> --display-name "Game name"
```

The resulting IPA is unsigned; sign it with Sideloadly/AltStore.

## Known limitations

- Early development; only a small number of titles have been exercised.
- First run may hitch while new graphics pipelines compile; the pipeline cache
  makes later runs much smoother.
- The UI is a single-game shell: no game library, settings pages, save-state
  management or on-screen menu yet.
- Battery saves live in the app's Documents directory; import/export and
  save-state UI are not implemented yet.
- No camera, microphone, online play, cheats or texture packs.
- Not distributed through the App Store.
